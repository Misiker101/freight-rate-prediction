# Freight Rate Prediction - Solution

This is my solution for the freight rate prediction task. The goal is to predict freight spot rates (`posted_rate`) for individual loads based on
lane, distance, weight, equipment type, and market signals across December 2025.

## Setup

```bash
git clone https://github.com/Misiker101/freight-rate-prediction.git

cd freight-rate-prediction

python -m pip install -r requirements.txt
```

Drop original data files into `data/`:
- `data/train_test.csv`
- `data/validation.csv`
- `data/validation_predictions_template.csv`
- `data/december_chart_inputs.csv`

For convenience I have put the dataset here, so you can run the script right away

```bash
python src/train.py

python src/predict.py

python score.py --predictions validation_predictions.csv --december-predictions data/december_chart_inputs.csv
```

## Validation strategy
I split by date instead of doing a random train/test split. The data runs Jan–Oct 2025, and we need to predict Nov–Dec, so a random split would basically let the model cheat by seeing October loads right next to September loads. That is not realistic for a forecasting problem.
What I did:
- Train: Jan 1 – Aug 31, 2025 (~38k rows)
- Holdout: Sep 1 – Oct 31, 2025 (~9.5k rows)

This mimics the real gap between train_test.csv and validation.csv, so the holdout score is actually honest.

## Model choice

I went with scikit-learn's HistGradientBoostingRegressor. Main reasons:
- Native categorical support (no one-hot explosion for pickup/delivery/equipment)
- Handles the mixed feature types well
- I used loss="absolute_error" because the target has a small cluster of  crazy outlier rates (3-7x normal), and L1 is way more robust to that than squared error

I trained a plain linear regression baseline just to sanity-check that the model is actually doing something useful.

I also trained LightGBM, the two models are statistically tied and have close predictive accuracy, but HGBR's MAE/RMSE is slightly better ($109.83/$635.09 MAE/RMSE compared to LightGBM's $111.25/$635.40 MAE/RMSE).
